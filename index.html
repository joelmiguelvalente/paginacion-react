01 · El motivo

¿Por qué se pagina?

Imaginá que tenés 120 productos en tu base de datos. Mostrarlos todos de una es como querer leer un libro entero de una sola mirada: pesado, lento y confuso.

⚡

Rendimiento

Se reduce el tiempo de carga inicial: pedí solo un puñado de registros, no todos.

🧭

Experiencia de usuario

La interfaz responde mejor y la persona sabe siempre dónde está: «voy por la página 3 de 30».

📈

Escalabilidad

El mismo código sirve para 20 productos o para 20.000. Cambiás el límite, no la idea.

💾

Consumo de recursos

Menos memoria en el navegador y menos ancho de banda viajando por la red.

«Un paginador es un componente de interfaz de usuario que divide un conjunto grande de datos en páginas más pequeñas y manejables. En lugar de cargar todos los registros de una vez, muestra solo un subconjunto específico (por ejemplo, 10 productos por página) y proporciona controles para navegar entre las diferentes páginas.»

🔥
En el curso lo hacían con Firebase. Ahí el paginador era de «Cargar más»: limit(PRODUCTOS_POR_PAGINA) para pedir 4 productos y startAfter(ultimoVisible) para seguir desde el último documento. 02 · La lógica

Las 4 cuentas de toda paginación

Antes de tocar un botón, entendé qué pasa adentro. Esto es lo único que realmente tenés que saber.

1

¿Cuántas páginas hay?

totalPaginas = Math.ceil(
	totalProductos / POR_PAGINA
);

Redondeamos hacia arriba porque 5 productos de 4 dan 2 páginas, nunca 1,25.

2

¿Desde dónde corto?

inicio = (paginaActual - 1) * POR_PAGINA;

Página 1 empieza en 0, página 2 en 4, página 3 en 8. Es un índice de array.

3

¿Hasta dónde corto?

fin = inicio + POR_PAGINA;
visibles = productos.slice(inicio, fin);

slice no incluye el índice final: por eso de 0 a 4 salen 4 productos (0, 1, 2, 3).

4

¿Los botones se pueden apretar?

puedeAtras   = paginaActual > 1;
puedeAdelante = paginaActual < totalPaginas;

Si no hay página anterior o siguiente, el botón se deshabilita. Nunca dejés ir a la página 0 ni a la 31.

🎯
El error más común (off-by-one): olvidar que los arrays empiezan en 0 pero las páginas empiezan en 1. Por eso se resta 1 a paginaActual para calcular inicio.
🧩
Cómo está organizado el código de abajo. Cada paso tiene tres bloques separados y coloreados: (1) el custom hook con toda la lógica y el estado, (2) el componente que solo dibuja lo que el hook le devuelve, (3) los datos y el App que lo ponen en marcha. Separar así te permite cambiar la interfaz sin romper la paginación y reutilizar la lógica en varios listados.

1 Custom hook la lógica 
import { useState } from 'react';

/* ============================================================
	 CUSTOM HOOK: toda la lógica de paginación vive acá
	 ============================================================ */
export function usePaginacionSimple(items, porPagina = 4) {
	// Estado: cuando cambia, React vuelve a dibujar el componente.
	const [paginaActual, setPaginaActual] = useState(1);

	// 1. ¿Cuántas páginas hay? Math.ceil redondea hacia arriba.
	const totalPaginas = Math.max(1, Math.ceil(items.length / porPagina));

	// 2 y 3. Las páginas empiezan en 1, los arrays en 0: se resta 1.
	const inicio = (paginaActual - 1) * porPagina;
	const fin = inicio + porPagina; // slice NO incluye el índice "fin"
	const productosVisibles = items.slice(inicio, fin);

	// 4. Estos booleanos evitan ir a la página 0 o a la página 31.
	const puedeAnterior = paginaActual > 1;
	const puedeSiguiente = paginaActual < totalPaginas;

	function anterior() {
		setPaginaActual((p) => Math.max(1, p - 1));
	}

	function siguiente() {
		setPaginaActual((p) => Math.min(totalPaginas, p + 1));
	}

	function irAPagina(n) {
		if (n >= 1 && n <= totalPaginas) setPaginaActual(n);
	}

	// Devolvemos datos + funciones. El componente no calcula nada.
	return {
		paginaActual, totalPaginas, inicio, fin, productosVisibles,
		puedeAnterior, puedeSiguiente, anterior, siguiente, irAPagina
	};
}
2 Componente dibuja 
import { usePaginacionSimple } from './usePaginacionSimple';

/* COMPONENTE: solo dibuja lo que el hook le devuelve */
function ListadoSimple({ productos }) {
	const {
		paginaActual, totalPaginas, productosVisibles,
		puedeAnterior, puedeSiguiente, anterior, siguiente
	} = usePaginacionSimple(productos, 4);

	return (
		<section>
			<h2>Productos nacionales</h2>
			<p>Página {paginaActual} de {totalPaginas}</p>

			<ul>
				{productosVisibles.map((producto) => (
					// key le dice a React cuál fila reutilizar: usá un ID, no el índice
					<li key={producto.id}>
						{producto.nombre} — ${producto.precio} · stock {producto.stock}
					</li>
				))}
			</ul>

			<button onClick={anterior} disabled={!puedeAnterior}>
				‹ Anterior
			</button>
			<button onClick={siguiente} disabled={!puedeSiguiente}>
				Siguiente ›
			</button>
		</section>
	);
}

export default ListadoSimple;

import { usePaginacionSimple } from './usePaginacionSimple'; // hook del paso 1

/* ============================================================
	 CUSTOM HOOK: reutiliza el paso 1 y agrega los números
	 ============================================================ */
export function usePaginacionNumerada(items, porPagina = 4) {
	// No repetimos las cuentas: el hook simple ya da página, límites y slice.
	const pagina = usePaginacionSimple(items, porPagina);

	// Array.from({ length: n }, (_, i) => i + 1) devuelve [1, 2, 3, ...]
	const numeros = Array.from(
		{ length: pagina.totalPaginas },
		(_, indice) => indice + 1
	);

	// ...pagina copia todo lo anterior y le suma "numeros".
	return { ...pagina, numeros };
}

import { usePaginacionNumerada } from './usePaginacionNumerada';

function ListadoNumerado({ productos }) {
	const {
		paginaActual, totalPaginas, numeros, productosVisibles,
		puedeAnterior, puedeSiguiente, anterior, siguiente, irAPagina

		<section>
			<p>Página {paginaActual} de {totalPaginas}</p>

				{productosVisibles.map((p) => (
					<li key={p.id}>{p.nombre} — ${p.precio}</li>

			</ul>

			<nav aria-label="Páginas">

				))}

import { useMemo } from 'react';
import { usePaginacionNumerada } from './usePaginacionNumerada'; // paso 2

/* ============================================================
	 FUNCIÓN PURA: produce los botones. Misma entrada = misma salida.
	 ============================================================ */
function construirPaginas(actual, total, ventana = 6) {
	// Si hay pocas, mostramos todas igual que en el paso 2.
	if (total <= ventana + 2) {
		return Array.from({ length: total }, (_, i) => ({
			tipo: 'numero', valor: i + 1
		}));
	}

	// Ventana de 6: 2 antes + la actual + 3 después.
	let izq = Math.max(2, actual - Math.floor((ventana - 1) / 2));
	let der = Math.min(total - 1, izq + ventana - 1);
	izq = Math.max(2, der - ventana + 1); // corro si se pasó del final

	const resultado = [{ tipo: 'numero', valor: 1 }]; // el 1 siempre va

	if (izq > 2) {
		// Hueco entre el 1 y la ventana → punto suspensivo a la izquierda
		resultado.push({
			tipo: 'dots', dir: -1, destino: Math.max(1, izq - ventana)
		});
	}

	for (let p = izq; p <= der; p++) {
		resultado.push({ tipo: 'numero', valor: p });
	}

	if (der < total - 1) {
		// Hueco hasta el final → punto suspensivo a la derecha
		resultado.push({
			tipo: 'dots', dir: 1, destino: Math.min(total, der + ventana + 1)
		});
	}

	resultado.push({ tipo: 'numero', valor: total }); // el último siempre va
	return resultado;
}

/* ============================================================
	 CUSTOM HOOK: reutiliza el paso 2 y agrega la ventana
	 ============================================================ */
export function usePaginacionAvanzada(items, porPagina = 4, ventana = 6) {
	const pagina = usePaginacionNumerada(items, porPagina);

	// useMemo evita recalcular si no cambiaron página, total o ventana.
	const paginas = useMemo(
		() => construirPaginas(pagina.paginaActual, pagina.totalPaginas, ventana),
		[pagina.paginaActual, pagina.totalPaginas, ventana]
	);

	return { ...pagina, paginas, ventana };
}

import { useState } from 'react';
import { usePaginacionAvanzada } from './usePaginacionAvanzada';

/* COMPONENTE: números, "…" clicables y controles extra */
function ProductosAvanzados({ productos }) {
	const [ventana, setVentana] = useState(6);
	const [destino, setDestino] = useState('');

	const {
		paginaActual, totalPaginas, inicio, fin,
		productosVisibles, paginas,
		puedeAnterior, puedeSiguiente,
		anterior, siguiente, irAPagina
	} = usePaginacionAvanzada(productos, 4, ventana);

	function irAlInput() {
		const n = Number(destino);
		if (n >= 1 && n <= totalPaginas) irAPagina(n);
		setDestino('');
	}

	return (
		<section>
			<label>
				Ventana:
				<select value={ventana}
					onChange={(e) => setVentana(Number(e.target.value))}>
					<option value={4}>4</option>
					<option value={6}>6</option>
					<option value={8}>8</option>
				</select>
			</label>

			<label>
				Ir a página:
				<input
					type="number" min={1} max={totalPaginas}
					value={destino}
					onChange={(e) => setDestino(e.target.value)}
					onKeyDown={(e) => e.key === 'Enter' && irAlInput()}
				/>
				<button onClick={irAlInput}>Ir</button>
			</label>

			<p>Página {paginaActual} de {totalPaginas} · productos {inicio + 1}–{fin}</p>

			<ul>
				{productosVisibles.map((p) => (
					<li key={p.id}>{p.nombre} — ${p.precio}</li>
				))}
			</ul>

			<nav aria-label="Páginas">
				<button onClick={anterior} disabled={!puedeAnterior}>‹ Anterior</button>

				{paginas.map((item, i) =>
					item.tipo === 'dots' ? (
						// Los "…" son botones de salto con destino guardado
						<button key={`dots-${i}`}
							onClick={() => irAPagina(item.destino)}
							aria-label={item.dir < 0
								? 'Saltar páginas atrás'
								: 'Saltar páginas adelante'}>
							…
						</button>
					) : (
						<button key={item.valor}
							className={item.valor === paginaActual ? 'activo' : ''}
							aria-current={item.valor === paginaActual ? 'page' : undefined}
							onClick={() => irAPagina(item.valor)}>
							{item.valor}
						</button>
					)
				)}

				<button onClick={siguiente} disabled={!puedeSiguiente}>Siguiente ›</button>
			</nav>
		</section>
	);
}

export default ProductosAvanzados;

La regla de los «…»

						
    
							
  1. La página 1 y la última siempre se dibujan.
    2. 
							
  2. Calculamos una ventana de 6 páginas cerca de la actual.
    3. 
							
  3. Si entre el 1 y la ventana hay un hueco, ponemos ….
    4. 
							
  4. Si entre la ventana y el final hay un hueco, ponemos otro ….
    5. 
							
  5. Si no hay hueco (pocas páginas), no hay puntos: se muestran todas.
    6. 
						

					

					

						
Anatomía del código

						
    
							
  • construirPaginas es una función pura: no usa estado, solo transforma datos. Es fácil de probar.
    • 
							
  • Devuelve objetos { tipo: 'numero', valor: 9 } o { tipo: 'dots', destino: 3 }.
    • 
							
  • El hook usa useMemo con dependencias: solo recalcula cuando cambia algo relevante.
    • 
							
  • El componente pregunta item.tipo === 'dots' y decide qué botón dibujar.
    • 
							
  • Cada … guarda un destino: por eso el salto funciona sin mirar índices.
    • 
							
  • key={`dots-${i}`} es único aunque haya dos puntos suspensivos.
    •
